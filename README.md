# kilo-skills

Скиллы для Kilo (агентный CLI) из воркшопа по вайбкодингу. Каждый скилл — папка с `SKILL.md` в формате YAML frontmatter + инструкции.

## Скиллы

| Скилл | Что делает | Триггеры |
| --- | --- | --- |
| `brainstorm` | Превращает расплывчатую идею в ясное видение: вопросы по одному, варианты подходов, стресс-тест, резюме с открытыми вопросами | «хочу что-то сделать», «побрейнштормим», «не понимаю что хочу» |
| `specification` | Оформляет поток мыслей или итог брейншторма в структурированную спеку `spec.md`: проблема, цели, не-цели, требования, критерии приёмки | «напиши спеку», «оформи в спеку» |
| `spec-refine` | Доводит черновик спеки до готовности к ревью: сверка с репозиторием, вопросы автору по развилкам, правки с сохранением стиля автора | «уточни спеку», «дополни ТЗ», «проверь спецификацию» |

## Болванка стартового проекта

Папка [`starter/`](starter/) — стартовая заготовка для практических сессий: база знаний `CLAUDE.md`, пример данных `prodazhi.csv`, инструкция. Участник открывает её как проект и адаптирует под себя.

## Конвейер

```
идея → brainstorm → резюме → specification → spec.md → spec-refine → ревью → реализация
```

Скиллы сцеплены фразами-триггерами: брейншторм заканчивается предложением написать спеку, спека — предложением уточнить её или начать реализацию.
