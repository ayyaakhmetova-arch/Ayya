# Болванка стартового проекта

Стартовая заготовка воркшопа «Вайб-кодинг для руководителя» (AI Camp · 2026).
Откройте эту папку как проект в Claude / Codex — и работайте от неё.

## Как начать

1. Откройте папку как проект в приложении (карточка проекта, не чат)
2. Первый промпт — **«Сделай мне хорошо»** (сессия 1 воркшопа)
3. Дальше — итерации маленькими шагами: промпт → результат → правка

## Что внутри

- `CLAUDE.md` — база знаний проекта: агент читает её автоматически в каждом новом чате
- `prodazhi.csv` — пример данных для отчёта: дата, менеджер, сумма, статус

## Адаптируйте под себя

Замените `prodazhi.csv` на свои данные, дополните `CLAUDE.md` описанием своей задачи — и болванка станет вашим проектом.
