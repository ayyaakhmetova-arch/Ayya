# Стартовый проект (болванка)

Проект-заготовка участника воркшопа «Вайб-кодинг для руководителя» (AI Camp · 2026).
Участник описывает автоматизацию словами — агент пишет код.

## Что здесь

- `README.md` — инструкция для участника
- `prodazhi.csv` — пример данных: дата, менеджер, сумма, статус

## Правила работы агента

- Результат — самодостаточные файлы: `.html` открывается двойным кликом, без установки чего-либо
- Одна фича за раз: маленькие шаги, а не «система посложнее» сразу
- После каждой рабочей версии — коммит (сохранение), чтобы откат был под рукой
- Секреты и ключи — только в `.env`, никогда в код и в чат
